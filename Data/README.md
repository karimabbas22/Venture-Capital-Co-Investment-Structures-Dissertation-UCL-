# Data

Place the three raw Refinitiv files directly in this folder before running the pipeline:

| File | Description |
|---|---|
| `Yearly Company Deal Level Data.xlsx` | US VC deals, one row per (startup, round, investor). |
| `Exit Data 2010-2024 US Refinitiv.xlsx` | US exit events. |
| `Company Datas.xlsx` | Company-level summary (supplementary). |

Everything else in this folder (a `processed/` subfolder, parquet files, trained models, graphs) is generated by running `Scripts/01_clean_data.py` onward — nothing else needs to be added manually.

## How the raw data was extracted

Source: **Refinitiv Eikon terminal**. Common filters applied to every pull:

- **Date range:** Jan 2000 – Dec 2024
- **Deal type:** Venture Capital deals only

### 1. `Yearly Company Deal Level Data.xlsx`

1. Open the **Deals Screener** app in Eikon, screening universe **Private Equity / VC**.
2. Set the date range filter to Jan 2000 – Dec 2024.
3. Set the deal-type filter to Venture Capital deals, US only.
4. Add the following fields to the report/output columns (these are the exact Eikon field names the pipeline expects — see `Scripts/pipeline_core.py:DEAL_COL_MAP`):
   - Investee Company Name
   - Investee Company Nation
   - Investee Company TRBC Economic Sector
   - Investment Date
   - Round Number
   - Round stage (unlabeled column immediately after Round Number)
   - Firm Investor Name
   - Firm Investor Organization Id
   - Fund Investor Name
   - Investor Equity Total (USD, Millions)
   - Disclosed Fund Equity Contribution (USD, Millions)
   - Round Equity Total (USD, Millions)
   - Disclosed Debt Contribution (USD, Millions)
   - Deal Value (USD, Millions)
   - Deal Rank Value (USD, Millions)
   - Venture Capital Deals
   - Investee Company Status
   - Investee Company State/Region
   - Investee Primary NAICS 2022
   - Firm Investors First Investment Date
   - Investee Company Total Funding Received To Date (USD)
   - Investee Company First Investment Received Date
   - Investee Company Last Investment Received Date
   - Investee Company Number Of Investments Received To Date
   - Investee Company Number Of Investor Firms To Date
   - Investee Company Founded Date
   - Investee Company All Investor Firms
   - Investee Company Current Operating Stage
   - Investee Company Current Investor Firms
   - Investee Company Historical Investor Firms
   - Fund Investors Portfolio Company Participation Rounds
   - Investee Company IPO Date
   - Investee Portfolio Status
   - Investee Company PermID
   - Investee Company Current Public Status
   - New Or Follow on Investment Indicator
   - Investee Primary SIC
   - Pure Venture Capital Deals
   - Investee Company Number Of Employees Most Recent Year End
5. Run the screen, one row per (startup, round, investor).
6. Export the results directly to Excel (Eikon's built-in "Export to Excel" option) and save as `Yearly Company Deal Level Data.xlsx`.

### 2. `Exit Data 2010-2024 US Refinitiv.xlsx`

1. In the same Deals Screener, switch to the **Exits** view (or run a separate exits screen) with the same US / VC-backed filters and the date range.
2. Add the following fields (see `Scripts/pipeline_core.py:EXIT_COL_MAP`):
   - SDC Deal Number
   - Company Name
   - Exit Type
   - Date Announced / Filed
   - Date Completed / Issued
   - Exit Date Completed / Issued
   - Ticker
   - Proceeds Amt + Overallot Sold All Markets (USD)
   - Acquiror Name
   - Time to Exit (Years)
   - No. of Deals
   - No. of IPOs
   - Exit Portfolio Company TRBC Economic Sector
   - Exit Portfolio Company TRBC Industry Group
   - Exit Portfolio Company TRBC Industry
   - Exit Portfolio Company Nation
3. Run the screen, one row per exit event.
4. Export to Excel and save as `Exit Data 2010-2024 US Refinitiv.xlsx`.

### 3. `Company Datas.xlsx`

1. Use Eikon's **Company Search** tool to pull one row per company (the same US VC-backed universe covered by the deal screen above, same date range).
2. Add the company-level fields available in that tool that overlap with the Investee Company fields listed in step 1 (e.g. sector, nation, founded date, status, employee count) — any of these that match a `DEAL_COL_MAP` key get renamed automatically by `Scripts/01_clean_data.py`; extra columns are kept as-is.
3. Export to Excel and save as `Company Datas.xlsx`.

Once all three files are in this folder, run `Scripts/01_clean_data.py` to regenerate everything downstream.
