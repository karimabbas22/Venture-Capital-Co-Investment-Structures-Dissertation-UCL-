# Data

Place the three raw Refinitiv files directly in this folder before running the pipeline:

| File | Description |
|---|---|
| `Yearly Company Deal Level Data.xlsx` | US VC deals, one row per (startup, round, investor). |
| `Exit Data 2010-2024 US Refinitiv.xlsx` | US exit events. |
| `Company Datas.xlsx` | Company-level summary (supplementary). |

Everything else in this folder (a `processed/` subfolder, parquet files, trained models, graphs) is generated by running `Scripts/01_clean_data.py` onward — nothing else needs to be added manually.
